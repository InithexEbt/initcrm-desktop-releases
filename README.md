# Init.CRM Desktop: descargas

Instaladores de la app de escritorio de [Init.CRM](https://www.initcrm.com). Este repositorio solo publica los binarios; no contiene código.

| Sistema | Última versión |
|---|---|
| macOS (Intel y Apple Silicon) | [Init.CRM-mac.dmg](https://github.com/InithexEbt/initcrm-desktop-releases/releases/latest/download/Init.CRM-mac.dmg) |
| Windows 10/11 | [Init.CRM-windows.exe](https://github.com/InithexEbt/initcrm-desktop-releases/releases/latest/download/Init.CRM-windows.exe) |

## Primera apertura
Los instaladores todavía no están firmados.

- **macOS:** si aparece «no se puede verificar el desarrollador», ve a Ajustes del Sistema → Privacidad y seguridad → «Abrir igualmente».
- **Windows:** si aparece SmartScreen, pulsa «Más información» → «Ejecutar de todas formas».
